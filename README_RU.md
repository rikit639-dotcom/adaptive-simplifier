# adaptive-simplifier

Плагин для JOSM, реализующий алгоритм адаптивного упрощения линий.

## Описание
Подробное описание: [OSM Wiki](https://wiki.openstreetmap.org/wiki/RU:JOSM/Plugins/AdaptiveSimplifier)

## Установка

1. Скачайте файл `adaptive-simplifier.jar` из раздела Releases.
2. Скопируйте его в папку плагинов JOSM.
3. Перезапустите JOSM.
4. В меню **Мои инструменты** появится пункт **Адаптивное упрощение**.

## Использование

1. Выделите одну или несколько линий (Way).
2. Перейдите в меню **Мои инструменты → Адаптивное упрощение** или нажмите `Ctrl+Shift+Y`.
3. Настройте параметры и нажмите **ОК**.
