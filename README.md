# adaptive-simplifier

JOSM plugin implementing adaptive line simplification algorithm.

## Description
Details: [OSM Wiki](https://wiki.openstreetmap.org/wiki/JOSM/Plugins/AdaptiveSimplifier)

## Installation

1. Download `adaptive-simplifier.jar` from Releases.
2. Copy it to your JOSM plugins folder.
3. Restart JOSM.
4. The tool will appear in the **Mytools** menu as **Adaptive Simplifier**.

## Usage

1. Select one or more ways.
2. Go to **Mytools → Adaptive Simplifier** or press `Ctrl+Shift+Y`.
3. Configure parameters (Threshold, Merge) and click **OK**.
